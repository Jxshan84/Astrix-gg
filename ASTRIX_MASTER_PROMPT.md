# Astrix Master Build Prompt

Build and maintain Astrix as a production Discord bot. Preserve working systems. Use Node.js 22+, discord.js v14, TypeScript/CommonJS-compatible runtime, MongoDB dashboard configuration sync, interactive components and English-only source.

## Required systems
- Modern conversational Astrix AI; never expose internal classifier labels such as `User Safety: safe`.
- Work V3: 100+ careers, 1,000+ distinct data-driven mini-job challenges, `/work list`, `/work apply`, `/work shift`, `/work stats`, `/work career`, `/work history`, `/work resign`, `/work notify`; 15-minute cooldown and persistent DM-ready notification.
- Advanced moderation: at least 50 practical actions with cases, reasons, notes, reports, filtered purge, voice moderation, channel/server controls, temporary punishments and staff stats.
- Economy: polished balance presentation with wallet, bank capacity/progress, net worth, Gems, credit score and career; bank/wallet limits; transfers, shops, loans and rewards.
- Preserve music, recording-link delivery, tickets, roles, security, giveaways, fun, privacy consent, premium and owner controls.
- Dashboard settings must be server-side validated and read by the bot via shared MongoDB configuration.
- Respect Discord global slash-command limits by grouping large systems.
- Before release, validate command option ordering, syntax/module compatibility, imports, startup command and configuration. Do not claim an unimplemented feature works.
