# Privacy Consent

Astrix blocks first-time economy, career, collection and social fun commands until the user accepts the current Privacy Policy version.

Environment variables:
- `PRIVACY_POLICY_VERSION=1.0`
- `PRIVACY_POLICY_URL=https://your-dashboard/privacy`

Acceptance stores only the accepted policy version and timestamp alongside the user profile. Change the version when a materially updated policy needs fresh consent.
