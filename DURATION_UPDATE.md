# Astrix v8.2.1 Duration Update

Moderation, Anti-Mention and timeout-based AutoMod configuration now accept compact durations:

- `30m` = 30 minutes
- `2h` = 2 hours
- `3d` = 3 days
- `1w` = 1 week

Discord timeout-backed features are limited to 28 days. Legacy stored Anti-Mention hour values remain readable.
